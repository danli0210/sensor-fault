# Phase II Research Report: Reliable Source Diagnosis Under Unknown Faults

**Status:** reproducible synthetic simulation, not yet a journal-level method.
**Reproducibility date:** 2026-10-20. No hardware experiments or real sensor datasets are claimed.

## 1. Hypothesis under test

A fault-source classifier that assumes exactly one known mechanism may become highly confident when the true event is a *compound process anomaly + sensor failure*. Active acquisition of extra channels can increase accuracy on in-dictionary cases while making false-confidence under out-of-dictionary cases more severe. An independently calibrated *model-adequacy check* may detect some such cases, but it will also be sensitive to noise-model mismatch.

This is a **hypothesis**, not a new theorem. Literature already covers observer-bank isolation, active fault diagnosis, and sensor selection. The purpose of Phase II is to identify whether there is a credible unresolved issue.

## 2. Dynamic experiment

Normal observations are generated by a stable, 4-state stochastic discrete-time system with 8 channels:

\[
 x_{t+1} = A x_t + G d_t + w_t,\qquad
 y_t = C x_t + f_t + v_t.
\]

The stochastic state and sensor noises are Gaussian. The *full time-correlated measurement covariance* follows from the stationary Lyapunov equation (not an independence approximation). Process events enter through `G`; sensor bias faults enter through `f`. In the single-source training dictionary, there are **two process events and two sensor faults**. Event amplitude is Gaussian with known nominal prior. There are 14 time steps per window, and events begin at time step 3.

Only sensors 0 and 1 are initially available. The policies are permitted to request **one** of sensors 2–7 for **50%** of the cases (selected on baseline-model entropy). The full-eight policy is a reference using more data and is NOT budget-matched.

The following 6 policies are compared:

- Direct (no additional channel).
- Best fixed channel selected using a separate calibration dataset (channel 4 in this run).
- Random additional channel.
- Four-hypothesis posterior-dispersion heuristic.
- Between-source-class conditional predictive dispersion heuristic (**class-aware**).
- All eight channels (unfair upper-reference, not budget-matched).

Both heuristics are approximate and have **no proven optimality**. All policies share the same query-eligible cases. Fixed-channel selection and goodness-of-fit calibration use **independent** synthetic calibration data.

## 3. Results

Five random seeds; 400 cases per seed **per regime** (2,000 per regime). These simulated cases are not field measurements. The values are arithmetic means over the five replicates.

| Scenario | Direct | Best fixed | Class-aware | Class-aware rejects as inadequately explained |
|---|---:|---:|---:|---:|
| Nominal dynamic model | 87.40% | 99.05% | 99.25% | 1.55% |
| Mild system mismatch | 86.70% | 99.20% | 99.30% | 1.65% |
| Stronger system mismatch | 84.25% | 95.15% | 97.15% | 4.25% |
| Noise standard deviation ×1.6 | 78.60% | 94.75% | 95.75% | **82.50%** |
| Unknown sensor-fault shape | 84.40% | 98.15% | 98.50% | 8.90% |
| Fault on previously unused auxiliary channel | 75.55% | **77.45%** | **62.55%** | 24.55% |

**Important:** accuracy measures binary labels only for the single-source regimes. When process anomalies and sensor faults occur at the same time, the binary truth label is *not well-defined*, so no binary accuracy is reported.

### Compound events (both causes present)

- Standard class-aware inference produces a confidently single-source decision in **97.10%** of compound examples (confidence ≥0.90, using aggregated posterior probability for each source class).
- A *separate* minimal generalized least-squares residual threshold, calibrated on independent nominal synthetic data to target ~1% nominal rejection, flags **92.20%** of the compound cases.
- The same gate rejects 1.55% of nominal matched cases; hence this model-adequacy detector shows promise in the specific synthetic setting, **not a general guarantee**.
- Under elevated noise (standard deviation ×1.6), the gate rejects **82.50%** of single-source cases, demonstrating severe model-mismatch sensitivity. A model-fit gate is not intrinsically robust.

### Paired analysis

For the nominal regime the difference between class-aware and best-fixed is only **+0.20 percentage points** across five seeds. Although the observed seeds consistently favor class-aware by a very small amount, the practical advantage is weak and can vanish with other model choices. In the auxiliary-fault regime the difference is **−14.90 percentage points**. This is clear evidence against an unconditional claim that active sensor selection is always more reliable.

## 4. Diagnostic adequacy gate

For each currently acquired subset of channels, define the generalized least-squares residual:

\[
  J_{\mathrm{fit}}(y) = \min_{h\in \mathcal H}\min_{a\ge 0}
   (y-a s_h)^T \Sigma^{-1}(y-a s_h).
\]

A gate rejects a decision if `J_fit` exceeds the empirical 99th percentile computed on *independent nominal* samples passed through the **same selection policy**. The threshold is policy-specific, since subset selection is itself data-dependent. This is a heuristic diagnostic consistency check, not a mathematically established distribution-free Type I/II error bound under shift.

## 5. Simple theoretical sanity check

For **two simple Gaussian hypotheses** with the same known covariance, fixed amplitude and equal priors, the optimal binary error is

\[
  P_e^{\mathrm{Bayes}} = \Phi\!\left(-\tfrac12
        \sqrt{(\mu_P-\mu_F)^T \Sigma^{-1}(\mu_P-\mu_F)}\right).
\]

`src/theory_check.py` independently compares the theoretical expression with simulated likelihood-ratio decisions for distinct channel sets. It agrees within Monte Carlo sampling error. This is standard statistical detection theory, **not a proposed new theorem**, and this exact expression does NOT cover the mixture-amplitude four-hypothesis experiment in full.

## 6. Main conclusions

1. The seemingly impressive nominal active-sensor accuracy is **not a convincing original contribution**, because the trained fixed-channel baseline nearly saturates performance.
2. Source-confident but invalid answers under simultaneous events are a more meaningful target than improving nominal classification from ~99.05 to ~99.25%.
3. A residual adequacy check identifies many synthetic compound events but fails badly under uncalibrated noise variation.
4. Faults of the requested channel are a serious blind spot. An active strategy that treats requested sensors as trustworthy can be substantially worse than a fixed policy.
5. A potentially worthwhile new direction is **risk-aware source discrimination with an explicit unknown/compound class, unreliable verification sensors, and a quantified cost–coverage–error tradeoff**, but careful literature review is still needed.

## 7. Immediate next study (Phase III)

Before claiming novelty, the following are essential:

1. Add a multi-label hypothesis space `{process, sensor, both, unknown}` rather than forcing mixed events into binary decisions.
2. Compare a robust observer-bank and sparse-fault residual method (not only simple fixed/random sensor policies).
3. Investigate adaptive calibration under measured operating noise changes, using **pre-event** data only and no test-label leakage.
4. Allow extra sensors to fail or be attacked. Formalize when trusted redundancy is unavailable and correctness is not identifiable.
5. Show calibration **risk–coverage** tradeoffs, unknown-event detection ROC, and additional-observation cost curves across varied systems.
6. Validate on a public real multichannel process dataset with transparent ground-truth caveats; injected sensor faults must be called *synthetic injections*.
